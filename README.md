Hello! Here you will find an "iOS hack" for the Samsung S9 SM-G960F (Exynos). 
Essentially, this involves running iOS on a Samsung device—which normally runs Android rather than iOS—much like a "Hackintosh" (running macOS on a PC designed for Windows). Please note that this is NOT official.

INSTALLATION GUIDE
You need TWRP—the latest official version:
twrp-3.7.0_9-0-starlte.img
LINK: https://eu.dl.twrp.me/starlte/twrp-3.7.0_9-0-starlte.img.html
Simply flash the file that begins with "sonion." Once the flashing process is complete (don't worry if any errors appear—that is normal), just reboot into the system.
